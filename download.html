Tutorial on How to Install and Download InTrique

Installed in three steps.

No account tools or extra software to set up first.

  1. 1

    Download the installer

    Select Download for Windows. The installer is one file: InTrique-Setup.exe.

  2. 2

    Run the installer

    Open the file and follow the prompts. When it finishes, InTrique appears in your Start menu.

  3. 3

    Launch and play

    Open InTrique, choose a world and jump in.
