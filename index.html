Questions about the download

Which systems does InTrique run on?

The client is available for Windows 10 and 11 (64-bit). macOS and Linux versions have not been released yet.

Windows shows a warning when I run the installer. Is that expected?

Windows can show a Microsoft Defender SmartScreen prompt for apps that are new or not widely downloaded yet. If you downloaded the installer from this page, select More info, then Run anyway. Only run InTrique installers from this official site.

How do I check that my download is genuine?

Open PowerShell in the folder that holds the installer and run Get-FileHash .\InTrique-Setup.exe -Algorithm SHA256 . The result should match the SHA-256 shown in the download details above.

Do I need a powerful computer?

See the minimum and recommended specs under System requirements. If a world looks wrong or runs slowly, updating your graphics drivers fixes most problems.

How do I get help or report a bug?

Contact support using the link in the footer. Include your InTrique version, your Windows version and your graphics card so we can reproduce the problem.
